# ART_SPEC.md — 美術與動畫整合說明

給 Codex 的美術交接文件。Codex 可以直接修改本檔，補充美術方向與規格。

## 風格基準

保留目前的暖色島嶼、紙張質感、深色描邊與繪本水粉風人物。改版優先順序：

1. 視覺一致性
2. 資訊層次（手機上一眼看懂現在要做什麼）
3. 動態回饋（政策實施、結果揭曉、後續影響）

美術要幫助學生理解：不同觀點如何分配國家、市場、家庭與社區的責任；政策如何影響居民生活；政策提案、實施與實際成果之間的差異。**不得醜化或美化任何觀點或族群。**

## 現有圖像在程式中的位置（`src/game.js`）

目前所有圖像都由程式即時產生 SVG，沒有圖片檔。

| 圖像 | 位置 | 說明 |
|---|---|---|
| 島民頭像 | `AV`（約 183 行）、`face(id, mood, …)`（約 197 行） | 11 位島民，`mood` 控制表情（開心、普通、不滿） |
| 島嶼場景 | `SCENE`（約 241 行）、`landscape(key, withFaces)`（約 254 行） | 主視覺與各情境背景 |
| 共用 SVG 定義 | `ART_DEFS`（約 298 行） | 漸層、紋理等共用 `<defs>` |
| 事件轉盤 | `wheelSVG()`（約 500 行） | 每屆開始的事件抽選 |
| 體制雷達圖 | `radar(f)`（約 424 行） | 結局的福利體制指標 |
| 成就徽章 | `medal(on, i)`（約 451 行） | 結局成就 |
| 慶祝動畫 | `confetti()`（約 672 行） | 已支援減少動態 |
| 色彩與字型 | `src/styles.css` 開頭的 CSS 變數（`--p-nr` 等政黨色） | 修改配色請改變數 |

行號會隨修改變動，請以函式名稱搜尋。

## 交付素材的方式

- 放進 `assets/` 的子資料夾：`characters/`、`scenes/`、`cards/`、`icons/`。
- 優先使用 **SVG**（檔案小、手機清晰）；點陣圖用 WebP 或 PNG，手機版最寬 780px（390px 的 2 倍）。
- 每個檔案都要登記到 `assets/manifest.json`，填寫用途、尺寸與版本。
- 島民頭像檔名：`characters/<島民id>_<表情>.svg`，例如 `characters/ma_happy.svg`（秀英阿嬤）。島民 id 對照見 `HANDOFF.md`。表情使用 `happy`、`neutral`、`upset`。

## 版面限制

- 手機直式，寬度 390px 為主；底部操作列固定。
- 文字不可放進圖片，以便日後修改內容。
- 所有動畫須提供 `prefers-reduced-motion` 版本，並且可以略過。
