## 1. 視覺方向與取捨

以已確認的「繪本島嶼與人物＋HTML 文字」為準，採暖紙底、墨藍框線、陶土與草木色。這批先使用原創、可編輯的 SVG 輪廓稿，確認人物辨識與資訊層次；水粉筆觸未大量製作。

| 方向 | 優點 | 代價 | 本次處理 |
|---|---|---|---|
| 繪本輪廓＋清楚的 HTML 卡片 | 文字易讀，素材可組合、可縮放 | 細緻水粉質感較少 | 採用，沿用老師決定 |
| 每張政策全幅插畫 | 情境鮮明 | 78 張卡成本高、手機捲動長 | 不作為收合卡；日後展開時可重用場景 |
| 純資訊面板 | 版面密度高 | 人物處境與故事感較弱 | 用於成本、責任欄位與數據 |

解決現有視覺混用：取消每個區塊都使用高飽和孔版色；海島與人物統一深色輪廓，介面只保留細框、低對比紙面與少量位移陰影。七觀點採相同字級、面積、框線與互動規格。

## 2. 三個手機畫面與現有程式對照

基準為 390×844；內容左右各 16px。桌面展示頁將手機樣稿與設計註記並排，正式遊戲桌面版建議沿用最大寬度 1080px，政策清單與說明欄並排。

| 畫面 | 區塊 | 程式／資料依據 | 本次表現 |
|---|---|---|---|
| 共用 | 屆數、國債、貧窮率、民怨 | HUD／`S` 的正式指標 | 不在手機隱藏貧窮率；無局勢資料顯示未提供 |
| 政策選擇 | 需求、既有方案、能力 | `rBudget` | 收合，先讓學生看到政策卡 |
| 政策選擇 | 政策名、成本、標籤 | `POL` p5、p6、p3 | 基準版原始名稱、成本與說明；不是新內容審核稿 |
| 政策選擇 | 責任與影響 | `roles`、`expect`、`views` 草案 | 展開可讀；尚未審核故用未提供 |
| 政策選擇 | 結餘＋公布政見 | `rBudget`／`#bar` | 固定於可視區底部；按鈕保留原意 |
| 開票結果 | 執政黨、票數 | `rResults` | 無資料不畫假比例或假排名；七觀點順序不是得票排名 |
| 開票結果 | 質詢與對手政見 | `rResults`／`QS` | 保留位置；正式版仍須先完成質詢才可確認執政 |
| 開票結果 | 島民回應 | `CIT`／政策 `say`／本局結果 | 無正式回應時顯示未提供，不假造台詞 |
| 體制揭曉 | 體制、指標、五屆紀錄 | `rFinal`／`regime()`／`radar()`／`S.history` | 缺資料不畫雷達圖；有正式資料時在同區域接回 |

已確認 390px 首屏可完整看到至少兩張收合政策卡。收合卡不附情境插畫；展開責任欄位後允許自然捲動。底部列不遮住主內容末端。正式版最多 4 張政見、財政計算、稅率與全部手牌仍由原遊戲處理，本樣稿只展示 3 張。

### 政策卡狀態

- 未選：白紙底、細框，按鈕「加入政見」。
- 已選：通用青色框、文字「已加入 ✓」、`aria-pressed=true`。不代表政策已實施。
- 展開：獨立按鈕＋`aria-expanded`／`aria-controls`，不要用整張卡點擊來同時選牌和展開。
- 已滿／停用：正式版保留卡片可讀與展開，選入按鈕停用並說明原因；本次沒有修改選牌上限邏輯。
- 陳情／事件限定：正式版以文字標籤識別來源，不用「正確」或「必選」色。
- 比較兩方案：手機以同欄位順序縱向比較，避免 358px 內兩個長文欄擠壓。此項為相對於舊 ART_INTEGRATION 並排要求的調整提案。

預期受益者、可能受損者分開列出，不以 `cit` 的正負支持度自動推論。沒有責任資料時不顯示 0 分或 0%。

## 3. 素材交付與組合方式

`assets/manifest.json` 已登記 19 個 SVG，尺寸、錨點、角色或圖層 id、用途、來源與檔案大小均可查。所有素材為本次直接編寫的原創向量路徑；沒有使用外部角色或素材庫圖片。

### 人物

- `characters/ma_{happy,neutral,upset}.svg`：秀英阿嬤，保留白髮髮髻、紫衣。
- `characters/ati_{happy,neutral,upset}.svg`：阿蒂，保留原角色頭巾與柔和衣色；不據此推定所有移工的宗教或穿著。
- viewBox：`0 0 512 512`；錨點 `[256,350]`；同角色所有表情輪廓與位置一致。
- SVG 根畫布透明，內含淡色圓形底與半身人物。置入新聞／卡片可用 68px；小尺寸 34–42px 建議只呈現頭像，不附細字。
- `happy` 對應原 happy；`neutral` 對應原 flat；`upset` 對應原 sad。不能依觀點固定某種表情。
- 示範動作是半身人物依序進場／傾聽；不是新的全身骨架或姿勢素材。

### 島嶼

底圖 `scenes/island_base.svg`；八個透明疊層 `island_{care,transport,housing,energy,community,health,school,industry}.svg`，全部 viewBox `0 0 780 430`、共同錨點 `[390,340]`。用同尺寸絕對定位疊圖即可；不要各自裁切。

**這些是服務領域符號，不能自行當成所有權、實際建設或成效證據。** 例如服務券不能直接畫成政府新建據點；能源政策也不一定是風力建設。Claude 須依已審政策對照表決定適用素材，沒有恰當圖層時用文字。每類只出現一次，同類多政策顯示清單或數量文字，不疊出大量建築。

## 4. 第三屆故事與動畫腳本

位置依已確認決定：`第三屆新聞 → 後果故事 → 公投 → 預算`。來源資訊與故事文字一開始就存在，動畫只帶出閱讀順序。

| 時間 | 動作樣張 | 保留的資訊 |
|---|---|---|
| 0–0.72 秒 | 秀英阿嬤上移 6px、淡入 | 來源政策、實施屆數、執政黨、是否玩家提案 |
| 0.72–1.56 秒 | 阿蒂上移 6px、淡入 | 兩位當事人的改善與落差 |
| 1.56–2.4 秒 | 人物停留，場景維持 | 衝突理由、三個縱向下一步方案 |
| 結束／略過 | 清除動畫 class 與 timer，保留最終畫面 | 不選牌、不加分、不推進流程 |

操作：「播放動作樣張」「略過動畫」與 Escape。2.4 秒自動結束。系統 `prefers-reduced-motion: reduce` 或樣稿手動減少動態開關生效時直接呈現終點；手動取消不能覆蓋系統的減少動態設定。離開畫面即清除 timer，重返不自動重播。

樣稿使用**缺少來源資料的一般回顧版本**，沒有假造政策後果。三個下一步按鈕因此停用。正式版有已審的政策資料時，才顯示可選政策卡並加入當屆手牌，不另計分。

### 建議整合契約（供 Claude 實作；本次沒有提供正式 runtime 模組）

```js
// 不同故事使用同一視覺模板；文字由已審資料提供。
{
  sources: [{ id, round, govParty, byPlayer }],
  sceneLayers: ['care'], // 須經政策對照檢查，不能僅憑政策標籤推論
  citizens: [{ id: 'ma', expression: 'neutral' }, { id: 'ati', expression: 'neutral' }],
  outcome: { citizenId, text },
  gap: { citizenId, text },
  conflict: { title, sides: [{ view, text }] },
  options: [{ policyId, title, reason }]
}
```

- `sources` 缺少有效紀錄：使用一般回顧，不作因果宣稱。
- `byPlayer=false`：標示他黨執政，不能寫成「你的政策」。
- 不認識的角色、表情或圖層：保留舊 `face()`／`landscape()` 後備；不猜測相近 id。
- 只有「執政確定／實施紀錄改變」事件更新正式島嶼；`render()` 或選牌不觸發施政動畫。
- 正式動畫容器放在 `#stage` 外；新增／移出政策時不可被 innerHTML 重建。事件需有穩定 key，避免重複播放。
- 正式介面可沿用 `mount / play / skip / setState / destroy` 草案。`skip`、重播、離開頁面都要完成／取消未完成 Promise，並清除 timeout 與事件監聽。
