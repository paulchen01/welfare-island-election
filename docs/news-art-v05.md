# 福利島新聞台美術與事件連動 v0.5

依老師提供的首頁／新聞台截圖，沿用既有水粉島嶼與 11 位模型人物，製作日常聚落及八事件插畫，直接接上正式遊戲程式的事件編號。延續 PR #7，未合併到 main。

## 設計與範圍

選用同一島嶼的八種事件場景，較單純加色罩更能表現現場，也比為每件事件製作整段影片輕巧。保持左側山丘、右側海灣及聚落位置。全景與現場特寫共用同一圖檔，由 HTML/CSS 選取觀看範圍，並非重新繪圖。

抽籤前顯示日常島嶼與「待播」。轉動時顯示連線中；停止後 S.event 同時決定畫面、標題、地點與原有事件影響。初始呈現現場特寫，可切回全島；屆數和事件名稱直接來自遊戲狀態。3500ms 轉盤時間不加長，事件畫面短轉場不阻擋操作，減少動態時停用轉場。沿用原政策、選票與財政計算。

事件場景是新聞情境示意，不表示玩家建成了新設施，亦非已驗證的政策成果。圖中不印文字、數字或意識形態標籤；標題與效果用 HTML 呈現。七觀點的教學內容改版仍不在本次範圍。
