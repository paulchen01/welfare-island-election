## 二、從遊戲邏輯角度需要你調整或留意的地方

1. **底部操作列不能拿掉財政結餘與「公布政見」**
   概念圖中間畫面的底部改成「比較方案／加入政見」。目前底部列即時顯示收入、支出、結餘，這是編預算時最重要的回饋，「公布政見」也是進入開票的唯一入口。
   最小調整：底部列保留「結餘＋公布政見」；「加入政見」放在每張卡片上（目前點卡片本身就是加入／取消）；「比較方案」放在卡片列表上方或卡片內。

2. **頂部指標請保留貧窮率**
   概念圖頂部只有國債、經濟、民怨。民怨主要由貧窮率累積而來，學生需要看到兩者的因果。目前手機上隱藏貧窮率，本來就列為已知問題。
   建議頂部手機版顯示：屆數、國債、貧窮率、民怨；經濟可收進展開區。

3. **每張政策卡附插畫的數量不可行**
   目前一般政策有 53 張，加上事件限定與陳情卡共 78 張。概念圖中，每張卡都有一幅情境插畫。
   建議：收合狀態不放插畫，只放分類圖示；展開後才顯示插畫，插畫以「島民＋場景」組合重用，不必每張政策各畫一幅。請你評估可行的數量。

4. **卡片變高後的捲動長度**
   每屆手牌有 10 張。若每張收合後仍有概念圖那麼高，手機上要捲很久才看得完。請以「收合狀態下，一個手機畫面內至少看得到兩張卡」為目標設計收合版。

5. **島嶼主畫面放在流程的哪裡，目前還沒有對應的畫面**
   程式目前沒有獨立的島嶼主畫面。島嶼插畫出現在標題海報和新聞頁的新聞插圖中。
   Claude 的建議：放在每屆新聞頁的最上方，取代現在的新聞插圖。這樣不用多一個步驟，也不會拉長遊戲時間。「提案預覽」則在編預算頁以小圖顯示。此事待老師決定。

6. **第三屆後果場景「三個下一步」要不要影響遊戲**
   目前沒有這個機制。Claude 的最小方案：學生選的方案會變成一張政策卡，加入第三屆的手牌，不另外新增計分系統。待老師決定是否這樣做。

7. **後果故事會依每局而不同**
   概念圖以托育為例。實際上每局實施的政策都不同，還可能是對手執政。所以場景要能在不同政策之間切換人物與背景，也要有「沒有相關政策時」的一般回顧版本。你在 DESIGN_REVIEW.md 已經提到這點，這裡只是確認需求一致。

## 三、Claude 會補的資料欄位（草案，可協商名稱）

```js
// 每張政策新增
roles: {
  provider: '政府直接提供' | '民間業者' | '社區組織' | '家庭' | ...,   // 文字，可多個
  payer:    '稅收' | '社會保險保費' | '使用者付費' | '雇主' | ...,       // 文字，可多個
  target:   '有托育需求的家庭'                                          // 文字
},
views: [ { view: '女性主義', why: '把照顧從家庭移到公共服務' }, ... ],   // 可多個觀點；七觀點改版定案後才填
expect: { gain: '預期改善的文字', concern: '需要考量的文字' },           // 編政見時顯示「預期」
// 實施後由程式記錄
enacted: [{ id, cost, round, govParty, byPlayer: true|false }]
// 第三屆後果（依實施中政策產生）
consequence: { sources:[{id, round, govParty, byPlayer}], outcome:{citizenId,text}, gap:{citizenId,text}, options:[...] }
```

這些都是教學內容，Claude 寫好初稿後會先請老師審閱，再交給你對照設計。在那之前，畫面可以先用「未提供」測試排版。
