# 決定：保守主義併入新右派

日期：2026-10-16（台北時間）
決定方式：陳老師指示「先查定義，再做決定」，Claude 查證後決定，由老師在 PR 審閱時最終確認。

## 決定

七觀點改版後，**不再有獨立的「保守主義」政黨**。原保守主義的家庭與社區主張併入**新右派**，原有的家庭類政策卡全部保留。

## 依據

社會政策的意識形態分類中，新右派一般被定義為兩支思潮的結合：

| 分支 | 層面 | 主張 |
|---|---|---|
| 新自由主義 | 經濟 | 小政府、自由市場、減稅、福利為殘補的最後防線 |
| 新保守主義 | 社會、道德 | 傳統家庭是社會的基石、社區與宗教團體先於國家、重視權威與共同價值、擔心福利造成依賴並破壞家庭 |

- 英國社會學與政治學教材將新右派描述為「自由市場經濟＋傳統社會價值」，並以傳統核心家庭作為社會政策的基礎。
- 台灣國考參考資料同樣指出：新右派在經濟上是新自由主義，在政治與社會上是新保守主義。

原保守主義政黨的主張（家庭責任、社區互助、三代同堂、家庭照顧者津貼、宗教與社區團體）都屬於上表的「新保守主義」分支。這些主張併入新右派後，不會遺漏任何內容，也符合七觀點的教科書分類。

## 對遊戲的影響（七觀點改版 #3 時處理）

- 新右派的政黨說明與質詢要同時呈現兩支：市場與家庭。
- 政策資料 v0.2 中，屬於家庭責任的新右派理由已標示「（新保守）」，學生能看出新右派內部有兩種理由。
- 新右派內部本身有張力：市場自由（例如放寬移工聘僱、彈性工時）與傳統家庭價值未必一致。這是可以放進質詢或學習單的教學點。
- 原保守主義的電腦對手（`PARTIES.co`）、偏好（`PREF.co`）、基本支持者（`BASEC.co`：秀英阿嬤、劉伯伯、阿德）需重新分配，並重做平衡模擬。
