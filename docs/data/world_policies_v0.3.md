# 世界各國政策卡 v0.3（19 張，待老師審閱）

老師要求每個觀點至少 15–20 張「符合理念」的一般政策卡。v0.2 時馬克思主義 8 張、綠色主義 13 張、女性主義 14 張，所以依世界各國實際政策新增 19 張；其中 3 張是中間偏右案例，維持左右平衡。

遊戲數值（成本、效果、島民反應）是遊戲用的簡化，不代表真實規模。卡片內容以 `world_policies_v0.3.py` 為唯一來源。
