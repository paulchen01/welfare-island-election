素材路徑為 `assets/characters/{id}-expressions.webp`，每張 780 × 260，透明背景，三格各 260 × 260。格序為 happy（開心）、neutral（平靜）、upset（擔憂）；保留 upset 程式鍵以相容 v0.3。11 張合計 746,636 bytes。

人物採日常服裝，尤瑪未套用未經考證的祭儀裝束；宇翔未以誇張眼部或障礙符號呈現。人物外貌是創作設計，不代表族群、職業或政治立場的固定樣貌。表情反映當下處境，不標示任何意識形態的優劣。

`src/art-preview.html?screen=characters` 可查看全部角色。圖片外的姓名、年齡、背景及表情文字均由 HTML 提供。圖集沿用 v0.3 的 CSS 裁切方式，動畫作用在外層容器，不能覆寫內層圖片的表情位移。整合示例見 [art-painted-v03.md](art-painted-v03.md)，新增提示詞見 [art-prompts-v04.md](art-prompts-v04.md)，最新資產清單為 manifest 0.4.0。
